# Architecture Decision Records (ADR)

本目录记录项目的关键架构决策。每个 ADR 包含：
- **状态**：提议 / 已采纳 / 已废弃
- **背景**：为什么需要做这个决策
- **决策**：选择了什么方案
- **原因**：为什么选择这个方案
- **后果**：这个决策带来的影响和约束
- **替代方案**：考虑过但未选择的方案
